# Integration records

`eu-ai-act-classifier.adapter.v1.json` is the adapter manifest through which the former EU Regulatory Data Toolkit consumed this classifier for its MCP release. The toolkit was retired on 25 September 2026 and the manifest moved here on 12 October 2026, so the record survives the toolkit's archival.

The manifest pins commit `65d2b12`, which is not on `main`. The tag `archive/eu-reg-adapter-pin-65d2b12` keeps it reachable. No current consumer reads this manifest. The matching PENDING row on AI Act classification through the MCP release is in [the claim ledger](../REGULATORY_CLAIM_LEDGER.md).
